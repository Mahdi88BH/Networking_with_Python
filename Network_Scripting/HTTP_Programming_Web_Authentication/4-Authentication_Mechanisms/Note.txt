    => Authentication in Python depends on whether you are consuming an external service (Client-side) or building an API/Web App 
    (Server-side).

---

-> 1. Client-Side Authentication (Consuming APIs)

- When writing Python scripts to interact with APIs, `requests` or `httpx` handle credentials using built-in or helper modules.

- A. HTTP Basic & Digest Auth
    - Basic Auth sends a Base64-encoded `username:password` string in the `Authorization` header. Digest Auth adds nonces and hashes 
    for extra security.

```python
import requests
from requests.auth import HTTPBasicAuth, HTTPDigestAuth

# Short-hand Basic Auth
res_basic = requests.get("https://httpbin.org/basic-auth/user/pass", auth=("user", "pass"))

# Digest Auth
res_digest = requests.get(
    "https://httpbin.org/digest-auth/auth/user/pass", 
    auth=HTTPDigestAuth("user", "pass")
)
```

- B. API Keys & Bearer Tokens (JWT)
    - Most modern APIs accept a long-lived API key or short-lived JSON Web Token (JWT) in headers.

```python
import requests

headers = {
    # Bearer / JWT Token
    "Authorization": "Bearer YOUR_JWT_TOKEN_HERE",
    # Alternative: Custom API Key Header
    "X-API-Key": "YOUR_API_KEY_HERE"
}

response = requests.get("https://api.example.com/data", headers=headers)
```

- C. OAuth 2.0 (Using `requests-oauthlib`)
    - For complex OAuth 2.0 flows (e.g., Google, GitHub, Microsoft sign-in):

```python
from requests_oauthlib import OAuth2Session

client_id = "YOUR_CLIENT_ID"
client_secret = "YOUR_CLIENT_SECRET"
redirect_uri = "https://yourapp.com/callback"

# 1. Direct user to authorize
oauth = OAuth2Session(client_id, redirect_uri=redirect_uri)
authorization_url, state = oauth.authorization_url("https://provider.com/oauth/authorize")
print(f"Go to this URL: {authorization_url}")

# 2. Fetch token using callback URL
redirect_response = input("Paste full callback URL: ")
token = oauth.fetch_token("https://provider.com/oauth/token", authorization_response=redirect_response, client_secret=client_secret)

# 3. Authenticated requests
res = oauth.get("https://provider.com/api/user")
```

- 2. Server-Side Authentication (Building Web APIs & Apps)
    - When building web applications or APIs in Python, authentication is typically implemented using one of three architectures:

- Summary of Server Framework Implementations

| Framework   | Mechanism          | Popular Packages / Tools                           | Best Used For                                          |
| ---         | ---                | ---                                                | ---                                                    |
| FastAPI     | JWT / Bearer Token | `PyJWT`, `passlib[bcrypt]`, `OAuth2PasswordBearer` | Modern async microservices & REST APIs                 |
| Django      | Session-Based      | Built-in `django.contrib.auth`                     | Full-stack web applications with server-side templates |
| Django REST | Token / JWT        | `djangorestframework-simplejwt`                    | Decoupled SPAs (React/Vue) or mobile app backends      |

- Example: Stateless JWT Auth in FastAPI
    - Here is how password hashing and JWT token creation work together in FastAPI:

```python
from datetime import datetime, timedelta, timezone
from fastapi import FastAPI, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
import jwt
from passlib.context import CryptContext

SECRET_KEY = "SUPER_SECRET_KEY_KEEP_SAFE"
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 30

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")
app = FastAPI()

# Utility Functions
def hash_password(password: str) -> str:
    return pwd_context.hash(password)

def verify_password(plain_password: str, hashed_password: str) -> bool:
    return pwd_context.verify(plain_password, hashed_password)

def create_access_token(data: dict):
    to_encode = data.copy()
    expire = datetime.now(timezone.utc) + timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES)
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

# Auth Endpoint
@app.post("/token")
def login(form_data: OAuth2PasswordRequestForm = Depends()):
    # Example hardcoded user check (replace with DB lookup)
    dummy_hashed_pw = hash_password("secret123")
    
    if form_data.username != "alice" or not verify_password(form_data.password, dummy_hashed_pw):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Incorrect username or password"
        )
    
    access_token = create_access_token(data={"sub": form_data.username})
    return {"access_token": access_token, "token_type": "bearer"}

# Protected Endpoint
@app.get("/protected-data")
def read_protected_data(token: str = Depends(oauth2_scheme)):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username: str = payload.get("sub")
        if username is None:
            raise HTTPException(status_code=401, detail="Invalid token")
        return {"message": f"Hello {username}, you accessed protected data!"}
    except jwt.PyJWTError:
        raise HTTPException(status_code=401, detail="Invalid or expired token")
```

- Best Practices Checklist
    1. Password Hashing: Always hash passwords with algorithms like **Argon2** or **Bcrypt** (`passlib`). Never store or log plaintext passwords.
    2. Environment Variables: Keep `SECRET_KEY`, API tokens, and credentials in a `.env` file using `python-dotenv` or `pydantic-settings`.
    3. Session vs. Token:
        * Use Cookies/Sessions for traditional browser web applications (provides built-in protection against XSS if `HttpOnly` and `SameSite` 
        flags are enabled).
        * Use JWTs/Tokens for stateless microservices, mobile apps, and cross-domain APIs.
    4. Transport Security: Ensure your production server enforces HTTPS; sending plain HTTP invalidates any authorization protocol.










    => Here is a comparison of HTTP Basic, HTTP Digest, and HTTP Bearer authentication, detailing how they function at the protocol level, 
    their security profiles, and how to implement them using Python.

---

- Comparison Overview

| Feature                | Basic Authentication                           | Digest Authentication                     | Bearer Authentication |
| ---                    | ---                                            | ---                                       | ---                                              |
| Header Format          | `Authorization: Basic <base64>`                | `Authorization: Digest <key=val>`         | `Authorization: Bearer <token>`                  |
| Credential Transmitted | Plaintext `username:password` (Base64 encoded) | MD5/SHA-256 hash using server nonce       | Cryptographic token (e.g., JWT, API Key)         |
| Replay Protection      | ❌ None                                        | ✅ Protected via nonce/nc counters        | ⚠️ Depends on token lifespan (`exp` claim)       |
| Requires HTTPS?        | 🚨 Mandatory (credentials easily decoded)      | Recommended (prevents MitM tampering)     | 🚨 Mandatory (stolen token gives full access)    |
| State / Storage        | Server checks username/password                | Server checks username/password           | Stateless (server verifies signature via secret) |
| Primary Use Cases      | Legacy systems, internal dev tooling           | Obsolete (rarely used in modern web APIs) | REST APIs, OAuth2, Microservices, Mobile Apps    |

- 1. HTTP Basic Authentication
    - Basic authentication encodes credentials as `username:password` using Base64. **Base64 is an encoding format, NOT encryption—anyone 
    sniffing raw HTTP traffic can instantly decode the credentials.

- How It Works:
    1. Client makes an unauthenticated request.
    2. Server responds with `401 Unauthorized` and `WWW-Authenticate: Basic realm="Restricted Area"`.
    3. Client encodes `username:password` into Base64 and attaches it to the request: `Authorization: Basic dXNlcjpwYXNz`.

- Python Client (`requests`):

```python
import requests
from requests.auth import HTTPBasicAuth

# Explicit syntax
response = requests.get('https://httpbin.org/basic-auth/user/pass', auth=HTTPBasicAuth('user', 'pass'))

# Tuple shortcut syntax
response = requests.get('https://httpbin.org/basic-auth/user/pass', auth=('user', 'pass'))
print("Basic Auth Status:", response.status_code)
```

---

- 2. HTTP Digest Authentication
    - Digest authentication was designed to fix Basic Auth's biggest flaw by never sending the password over the network. Instead, it uses 
    a challenge-response mechanism involving a server-generated nonce (number used once) and a cryptographic hash function (MD5 or SHA-256).

- How It Works:
    1. Client requests a protected resource.
    2. Server returns `401 Unauthorized` with a unique `nonce` value in the `WWW-Authenticate: Digest realm=...` header.
    3. Client hashes `username + password + realm + nonce + HTTP method + URI` into a response string.
    4. Client sends the hash to the server. The server computes the same hash locally using the stored user password and compares them.

- Python Client (`requests`):

```python
import requests
from requests.auth import HTTPDigestAuth

url = 'https://httpbin.org/digest-auth/auth/user/pass'

# requests handles the 401 challenge handshake and hashing automatically behind the scenes
response = requests.get(url, auth=HTTPDigestAuth('user', 'pass'))
print("Digest Auth Status:", response.status_code)
```

---

- 3. HTTP Bearer Authentication
    - Bearer authentication is the modern standard for RESTful APIs, OAuth 2.0, and microservices. The client presents a Bearer Token 
    (typically a signed **JSON Web Token / JWT** or opaque API key). The rule of Bearer authentication is simple: "Whoever bears (holds) 
    this token is granted access."

- How It Works:
    1. Client logs in once via a login endpoint (`POST /login`) using primary credentials.
    2. Server validates credentials and returns a signed token.
    3. Client attaches the token to subsequent requests: `Authorization: Bearer <TOKEN>`.
    4. The server validates the token's cryptographic signature and expiration without needing to look up the user in a database on every request.

- Python Client (`requests`):

```python
import requests

api_url = "https://api.example.com/user/profile"
jwt_token = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."  # Example JWT

headers = {
    "Authorization": f"Bearer {jwt_token}",
    "Accept": "application/json"
}

response = requests.get(api_url, headers=headers)
```

- Building a FastAPI Server Supporting Bearer Tokens (JWT)
    - Here is how Bearer Token authentication is implemented server-side in Python using FastAPI:

```python
from datetime import datetime, timedelta, timezone
from fastapi import FastAPI, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
import jwt

SECRET_KEY = "super-secret-key-change-in-production"
ALGORITHM = "HS256"

app = FastAPI()

# OAuth2 helper that extracts 'Bearer <token>' from the Authorization header
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

def create_access_token(data: dict):
    to_encode = data.copy()
    expire = datetime.now(timezone.utc) + timedelta(minutes=15)
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

@app.post("/token")
def login(form_data: OAuth2PasswordRequestForm = Depends()):
    # Dummy user validation (replace with hashed DB check)
    if form_data.username != "admin" or form_data.password != "secret":
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Incorrect username or password"
        )
    
    token = create_access_token({"sub": form_data.username})
    return {"access_token": token, "token_type": "bearer"}

@app.get("/protected")
def get_protected_data(token: str = Depends(oauth2_scheme)):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        return {"message": f"Access granted for user: {payload.get('sub')}"}
    except jwt.PyJWTError:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED, 
            detail="Invalid or expired token"
        )
```
